# A题“药材的烘干问题”支撑材料文件说明

## 1. 材料用途

本文件夹提供A题四问的可复现程序、输入数据、完整结果、论文图件和写作说明。

本材料不包含Python虚拟环境、缓存、LaTeX中间文件和临时渲染文件。题目原始PDF未重复收录；程序所需的附件1、附件2已包含。

## 2. 目录结构

```text
支撑材料/
├─ solve.py                         四问统一求解、Excel写入和绘图程序
├─ sensitivity_analysis.py          关键参数正负10%敏感性程序
├─ requirements.txt                 最小Python依赖
├─ 附件/
│  ├─ 附件1.xlsx                    烘房温度和环境水分浓度
│  ├─ 附件2.xlsx                    0--72 h药材半径
│  └─ 附件3/
│     ├─ result1.xlsx               问题一完整结果
│     ├─ result2.xlsx               问题二完整结果
│     ├─ result3.xlsx               问题三完整结果
│     └─ result4.xlsx               问题四完整结果
├─ 计算结果/
│  ├─ summary.json                  论文表格、阈值、网格误差和摘要指标
│  └─ parameter_sensitivity.json    参数敏感性原始数值
└─ figures/                         论文图件PNG
```

## 3. 运行环境

- Python 3.12.10
- NumPy 2.5.3
- SciPy 1.18.1
- openpyxl 3.1.5
- Matplotlib 3.11.1

在本文件夹中重建环境：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## 4. 复现命令

在“支撑材料”目录打开PowerShell：

```powershell
.\.venv\Scripts\python.exe .\solve.py
.\.venv\Scripts\python.exe .\sensitivity_analysis.py
```

第一条命令会读取 `附件/附件1.xlsx`、`附件/附件2.xlsx`，覆盖填写 `附件/附件3/result1.xlsx` 至 `result4.xlsx`，并更新 `计算结果/summary.json` 和 `说明书/figures/`。如只想复算JSON和图而不改写Excel，可运行：

```powershell
.\.venv\Scripts\python.exe .\solve.py --no-excel
```

说明书采用XeLaTeX编译，源文件为 `说明书/结果与代码说明书.tex`。该文档使用 `说明书/figures/` 下的图片。

## 5. 最终结果口径

- 问题三：207300 s（57.5833 h）为60 s输出网格上首个未经舍入且严格满足全域 `C<0.15` 的时刻，原始最大值为0.14998444。
- 问题四：189780 s（52.7167 h）为首个严格达标时刻，原始最大值为0.14999407，此时半径为1.2000 cm。
- 上述数值保留四位小数均显示为0.1500，属于舍入现象；前一60 s输出点均大于0.15。
- result3和result4继续保存至严格达标后0.5 h，并未在临界点立即终止。

## 6. 图件说明

`说明书/figures/` 中共10张PNG：

- `environment_extension.png`：附件1插值和平台延拓；
- `question1_profiles.png`、`question2_profiles.png`：代表时刻径向剖面；
- `question1_heatmaps.png`至`question4_heatmaps.png`：四问完整温度/水分时空场；
- `drying_threshold.png`：问题三、四全域最大含水率及严格达标点；
- `shrinkage_effect.png`：附录4同物性下固定/动态半径对比；
- `radius_and_comparison.png`：半径曲线和多模型达标时间对照。

热力图统一使用符合物理语义的色卡：温度由低到高为蓝—黄—橙—红；水分由低到高为浅黄—绿—蓝—深紫。问题四图中的白色区域表示该时刻已经位于收缩药材外部。

## 7. 文件校验与注意事项

- result1：1800个时间行、21个空间位置，温度/水分两个工作表；
- result2：10800个时间行、21个空间位置，温度/水分两个工作表；
- result3：每60 s输出至209100 s；
- result4：每60 s输出至191580 s，超出实时半径的固定位置有意留空；
- 所有Excel数值均保留四位小数，时间单位为s，距离单位为cm；
- 计算内部长度统一使用m、温度使用K，展示时再换回cm和摄氏度；
- 模型结果是题给经验参数下的数值预测，未经过额外真实药材实验标定。
